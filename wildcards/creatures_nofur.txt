# Non-furred creature wildcard. Format: name|family
# family drives body-covering/texture wording downstream -- NEVER "fur":
#   bird       -> feathers/plumage
#   reptile    -> hard scales
#   amphibian  -> smooth moist skin
#   fish       -> iridescent scales/fins
#   arthropod  -> chitin/carapace/exoskeleton (includes true crustaceans --
#                 crab/lobster/shrimp/barnacle -- Crustacea IS a subphylum
#                 of Arthropoda, and "hard exoskeleton" reads correctly on
#                 them; see 2026-07-31 reclassification note below)
#   cephalopod -> smooth rubbery skin, beaked/tentacled (true cephalopods
#                 only -- octopus/squid/cuttlefish/nautilus)
#   mollusk    -> hard shell / soft-bodied non-cephalopod sea life (snails,
#                 bivalves, echinoderms, cnidarians -- see note below)
#   mythical   -> scales (draconic/serpentine) unless noted
#   golem      -> the named inorganic material itself (stone/clay/crystal/
#                 obsidian/coral/metal), not skin at all -- also covers
#                 robots/androids/cyborgs/automatons (constructed, no flesh)
#   elemental  -> living material of the named element (fire/ice/magma/
#                 storm/earth/water/slime), constantly shifting, no skin
#   undead     -> bone, wrapped bandage, or desiccated leathery skin
#   spirit     -> translucent/incorporeal, no solid skin at all
#   demonkin   -> thick warty/leathery humanoid-monster hide (ogre/troll/
#                 demon archetype) -- NOT fur, NOT human skin
#   alien      -> only the genuinely novel alien/cosmic-horror look (grey
#                 alien, kaiju, eldritch/star-spawn horror, beholder); alien
#                 entries that clearly read as an existing family (alien
#                 REPTILIAN, alien CEPHALOPOD, INSECTOID alien, tentacled
#                 horror, mind flayer) are tagged with that family directly
#                 instead of a separate "alien" bucket, per Andrew's own
#                 framing of these as reuses, not a new look
#   plantfolk  -> bark, moss, fungal cap, root-woven skin
#   crystalline -> faceted, translucent, gem-like surface
# ("scalykin" from Andrew's own framing -- mythological humanoids that are
# scaled/feathered, not furred -- was likewise folded directly into
# reptile/bird rather than kept as its own bucket: medusa/lamia -> reptile,
# harpy -> bird, gorgon already existed in this file as mythical and was
# left there rather than duplicated.)
# Deliberately excludes ALL mammals (wolf/lion/bear/tiger/fox/panther/etc,
# and anything with hair/fur) and excludes any species whose common name
# embeds a mammal word (e.g. "leopard gecko", "tiger shark"), so a random
# pick can never read as a furry-fandom archetype. Same rule extends to the
# monster/construct entries added below: classic FURRED monster archetypes
# (yeti, bigfoot/sasquatch, minotaur, satyr, centaur, wendigo, werecreatures)
# are deliberately excluded even though they're iconic -- don't add them
# back in without a real texture plan for the fur problem.
#
# ADDED 2026-07-31, same round, Andrew mid-task looking at reference images
# he likes (an elephant/fox news-anchor pair, a Vader-helmet officer beside
# a bear officer, a reptilian-alien/unicorn/fox trio in suits): "Why can't
# we have all sort of weird creatures, like actual creatures, monsters,
# weird shit." The 325-entry real-animal-plus-classical-mythology pool above
# was too narrow -- added 61 monster/construct/alien entries (golems,
# elementals, undead, spirits, demonkin, aliens, plantfolk, crystal beings)
# below, same nothing-with-fur constraint, each with its own texture family
# (a golem is not a demon is not a ghost -- see the family list above).
#
# RECLASSIFIED 2026-07-31: the original "cephalopod" bucket lumped true
# cephalopods in with crustaceans, snails/bivalves, and echinoderms/
# cnidarians -- caught via a live test render of "pearl oyster" tagged
# cephalopod, which produced a mostly-human-skinned figure because "smooth
# rubbery slick skin, beaked maw, tentacled" is a true-cephalopod texture
# that doesn't fit an oyster at all. Split into three families instead:
# true crustaceans moved to arthropod (biologically correct, and "hard
# exoskeleton, carapace" is a BETTER texture match for a crab/lobster shell
# than the old bucket's rubbery-skin wording ever was); true cephalopods
# (octopus/squid/cuttlefish/nautilus) kept in cephalopod; everything else
# (snails, clams/oysters/scallops/chiton, starfish/urchin/sea cucumber,
# jellyfish/coral/anemone) moved to a new "mollusk" family with its own
# shell/soft-body texture and a head phrase that doesn't assume a face
# (several of these -- starfish, jellyfish, coral, anemone -- have no head
# at all in real life).
